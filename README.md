# Spring Boot TODO Manager
 
Java 21 + Spring Boot + MySQLで構築する学習用TODOアプリケーションです。
 
## 技術スタック
 
- **Java**: 21
- **Spring Boot**: 3.x
- **ビルドツール**: Maven
- **データベース**: MySQL 8.x
- **テンプレート**: Thymeleaf
- **セキュリティ**: Spring Security
- **ORM**: Spring Data JPA
- **GUIツール**: TablePlus
 
## 機能
 
- ユーザー認証（ログイン・設定）
- TODO管理（CRUD操作）
- ステータス管理（未完了・進行中・一時保留・完了）
- 優先度管理（高・中・低）
- 期限日管理
 
## 開発環境構築
 
1. MySQLを起動
2. TablePlusでデータベース接続
3. アプリケーション起動
 
## 学習目的
 
- Spring Bootの基礎
- Spring Securityによる認証
- JPAによるデータベース操作
- ThymeleafによるUI実装
- Git Flowによるバージョン管理
